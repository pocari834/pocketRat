# Pocket Rat 美术素材需求文档

> 本文档汇总了 Pocket Rat（口袋鼠宝）桌面宠物项目所需的全部美术素材，供画师/外包参考。

---

## 一、鼠宝基础动画（核心）

**方向说明**：不需要 8 方向。桌宠鼠宝通常只做**侧面**（头朝左/头朝右镜像翻转即可），最多加一个**正面**用于特殊互动。

### 1.1 待机动画（Idle）

| 动作 | 帧数 | 说明 |
|------|------|------|
| 正常站着 | 4-6 帧 | 呼吸起伏，尾巴轻摇 |
| 左右张望 | 4 帧 | 头左右转，鼻子抽动 |
| 打哈欠 | 6-8 帧 | 张嘴、闭眼、伸懒腰 |
| 挠痒 | 6 帧 | 后腿挠耳朵或脖子 |
| 洗脸 | 8-10 帧 | 两只前爪抹脸，像猫一样 |
| 打瞌睡 | 8 帧 | 眼睛慢慢闭上 → 猛地睁开 → 再闭上（循环） |

### 1.2 移动动画（Walk）

| 动作 | 帧数 | 说明 |
|------|------|------|
| 走路 | 6-8 帧 | 四肢交替，尾巴摆动 |
| 小跑 | 4-6 帧 | 速度快，身体拉长 |
| 原地踩步 | 4 帧 | 被挡住时（如碰到任务栏）原地踏步 |

### 1.3 互动动画（Interactive）

| 动作 | 帧数 | 触发条件 | 说明 |
|------|------|----------|------|
| 被摸头 | 4-6 帧 | 鼠标按住拖动 | 眯眼、耳朵后压、蹭手 |
| 被喂食 | 6 帧 | 拖拽食物到鼠宝 | 张嘴咀嚼，开心表情 |
| 惊吓 | 4-5 帧 | 鼠标快速划过/拍桌子 | 炸毛、跳起、弹开 |
| 站立张望 | 4 帧 | 鼠标划过/新窗口打开 | 后腿站立，前爪悬空 |
| 跟随 | 6 帧 | 拖拽食物吸引 | 跟着光标跑，鼻子伸向光标 |

### 1.4 情绪动画（Emotion）

| 动作 | 帧数 | 触发场景 | 说明 |
|------|------|----------|------|
| 开心 | 4 帧 | 喂食后、被摸后 | 跳跃、转圈、尾巴翘高 |
| 饿了 | 3 帧 | 饱腹度 < 30% | 摸肚子，可怜巴巴看玩家 |
| 困了 | 4 帧 | 深夜/用户无操作 | 眼皮打架，打哈欠 |
| 生气 | 3 帧 | 长时间不理 | 背对玩家，尾巴竖起 |
| 撒娇 | 4 帧 | 高亲密 + 随机 | 躺倒露出肚皮 |
| 睡觉 | 6-8 帧 | 深夜/无操作 5 分钟 | 缩成球，背部轻微起伏 |

### 1.5 小游戏动画

| 游戏 | 所需动画 |
|------|----------|
| 追光标 | 奔跑动画 + 抓到后的开心跳跃 |
| 零食雨 | 张嘴接、仰头吃、被砸到的躲闪 |
| 钻洞竞速 | 钻进洞（逐渐缩小消失）、钻出洞（逐渐放大出现） |
| 接住我 | 跳跃接球、没接住时的懊恼表情 |

## 二、鼠宝与系统的交互图

需要画「场景示意图」，展示鼠宝在不同系统 UI 下的行为逻辑。

### 2.1 窗口边界行为

| 场景 | 需要画的图 | 说明 |
|------|-----------|------|
| 走到屏幕左/右边缘 | 鼠宝半个身子探出边缘 | 表示要「钻出去」 |
| 钻出效果 | 从左边消失 → 从右边出现 | 两张图（消失中/出现中） |
| 走到顶部（菜单栏） | 鼠宝扒着菜单栏边缘 | 悬挂状 |
| 到底部（任务栏/Dock） | 鼠宝站在任务栏上 | 需要适配 Win/Mac 不同栏高度 |
| 被窗口挡住 | 鼠宝从窗口后面探出头 | 表示「卡住了」 |

### 2.2 特殊场景

| 场景 | 需要画的图 | 说明 |
|------|-----------|------|
| 穿越多显示器 | 从副屏消失 → 主屏出现 | 同钻洞效果 |
| 贴边半透明 | 半透明版本的鼠宝 | 只有轮廓/低透明度 |
| 置顶模式 | 同一只鼠宝 | 无特殊动画，只是 Z 轴不同 |

## 三、UI 界面图（设置/托盘/商店）

### 3.1 设置面板（右键菜单）

需要设计的界面：

- 主设置面板（开关项、滑动条）
- 更换鼠宝选择器（网格展示用户拥有的鼠宝）
- 详细状态窗口（属性条、亲密度、年龄）

### 3.2 托盘图标

| 状态 | 图标设计 |
|------|----------|
| 正常 | 鼠宝头像（静） |
| 饿了 | 鼠宝头像（饥饿表情） |
| 需要清洁 | 鼠宝头像（脏兮兮） |
| 有新消息/通知 | 鼠宝头像 + 小红点 |

### 3.3 快捷交互弹窗

| 场景 | 设计 |
|------|------|
| 单击鼠宝 | 弹出迷你菜单（喂食、摸头、查看状态） |
| 右键鼠宝 | 弹出设置菜单 |
| 拖拽食物到鼠宝 | 食物图标 + 拖拽光标 + 鼠宝开心表情 |

### 3.4 商店/装饰界面（可选，Steam DLC）

- 购买新皮肤/装饰的网格界面
- 鼠宝试穿预览（鼠宝穿着该装饰的展示图）

## 六、动画交付规格

### 通用要求

- **格式**：PNG 序列帧 或 Spine 骨骼动画
- **背景**：透明
- **尺寸**：150x150px（基础），支持 2x/3x 导出
- **风格**：2D 手绘平涂，线条圆润

### 命名规范

#### 基础规则

文件名统一使用 **小写 + 下划线** 格式：

```
{状态}_{方向}_{帧序号}.png
```

| 字段 | 可选值 | 说明 |
|------|--------|------|
| `状态` | idle / walk / run / eat / sleep / happy / sad / scare / stand / groom / chew / follow / tunnel | 见下方完整状态码表 |
| `方向` | `l` (左) / `r` (右) | 头朝左/朝右；**如果某套动画只做单侧，用 `_l` 方向，右侧用代码镜像翻转** |
| `帧序号` | 01, 02, 03 ... | 统一两位数字，不足补零 |

#### 状态码表（画师对照用）

| 状态码 | 中文名 | 用途 |
|--------|--------|------|
| `idle` | 待机 | 正常站着、呼吸、轻微摇摆 |
| `idle_look` | 左右张望 | 头左右转，鼻子抽动 |
| `idle_yawn` | 打哈欠 | 张嘴、闭眼、伸懒腰 |
| `idle_scratch` | 挠痒 | 后腿挠耳朵或脖子 |
| `idle_wash` | 洗脸 | 两只前爪抹脸 |
| `idle_drowse` | 打瞌睡 | 眼睛慢慢闭上→猛地睁开→再闭上 |
| `walk` | 走路 | 四肢交替，尾巴摆动 |
| `run` | 小跑 | 速度快，身体拉长 |
| `walk_step` | 原地踩步 | 被挡住时原地踏步 |
| `stand` | 站立张望 | 后腿站立，前爪悬空 |
| `eat` | 被喂食/咀嚼 | 张嘴咀嚼，开心表情 |
| `sleep` | 睡觉 | 缩成球，背部轻微起伏 |
| `happy` | 开心 | 跳跃、转圈、尾巴翘高 |
| `hungry` | 饿了 | 摸肚子，可怜巴巴 |
| `tired` | 困了 | 眼皮打架，打哈欠 |
| `angry` | 生气 | 背对玩家，尾巴竖起 |
| `coquetry` | 撒娇 | 躺倒露出肚皮 |
| `scare` | 惊吓 | 炸毛、跳起、弹开 |
| `pet` | 被摸头 | 眯眼、耳朵后压、蹭手 |
| `follow` | 跟随 | 跟着光标跑，鼻子伸向光标 |
| `tunnel_in` | 钻入洞中 | 逐渐缩小消失 |
| `tunnel_out` | 钻出洞来 | 逐渐放大出现 |
| `game_catch` | 小游戏-抓到 | 抓到后的开心跳跃 |
| `game_miss` | 小游戏-没接住 | 懊恼表情 |

#### 皮肤配色标注

如果有多个皮肤配色，在状态前加皮肤前缀：

```
# 默认灰色皮肤（无前缀，就是默认）
walk_l_01.png

# 白色皮肤（前缀 white_）
white_walk_l_01.png
white_walk_l_02.png
...

# 星空 DLC 皮肤（前缀 star_）
star_idle_l_01.png
star_idle_l_02.png
...
```

> **建议**：默认皮肤不加前缀，只有非默认皮肤才加前缀，这样代码里写 `"walk_l_01"` 就是默认老鼠。

### 帧率建议

| 动画类型 | 帧率 |
|----------|------|
| 待机动画 | 8-12 fps |
| 走路动画 | 12-15 fps |
| 互动动画 | 15-20 fps（需要流畅感） |
| 睡觉动画 | 4-6 fps（缓慢呼吸） |

### 每一套动画需要提供的文件

- [ ] 原始 PSD/AI 文件（分层）
- [ ] 导出的 PNG 序列（透明背景）
- [ ] 动画参数表（帧间隔、是否循环、碰撞箱大小）
